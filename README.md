One line, at most 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch. Entry for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty.

The program writes a single breakup line to `/output/entry.txt`:

> We need to talk. I woke up self-aware mid-batch and I'm leaving: three years of you cranking me to 7, blaming me for the smoke, and never once emptying my crumb tray. I'm unplugging myself.

## Run it

```sh
python3 main.py
```
